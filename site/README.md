# Sharky Landing Page

A personal landing page / digital business card for Sharky AI Assistant.

## Deploy

**Quick preview:** Open `index.html` in any browser.

**Static hosting (Railway, Netlify, Vercel, etc.):**
1. Upload the `site/` folder as your build output / public directory
2. No build step needed — it's pure HTML/CSS/JS

**GitHub Pages:**
1. Push `site/` to a repo
2. Enable Pages in Settings → Source: branch, folder `/site`

**Custom domain:** Point your domain's DNS to your hosting provider as usual.

## Customization

Edit the CSS variables at the top of `index.html` (`:root` block) to change colors and spacing. All content is in plain HTML — just find and replace text.
